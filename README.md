# 🎧 BeatLab Bot

Telegram-бот для битмейкеров: полезные инструменты, библиотека сэмплов и биржа совместной работы.
Написан на **Bun + TypeScript**.

## Стек

| Компонент | Технология |
|---|---|
| Рантайм | [Bun](https://bun.sh) |
| Язык | TypeScript (strict) |
| Bot API | [grammY](https://grammy.dev) |
| ORM | [Drizzle](https://orm.drizzle.team) + `bun:sqlite` |
| Валидация | [Zod](https://zod.dev) |

## Быстрый старт

```bash
# 1. Установить зависимости
bun install

# 2. Настроить окружение
cp .env.example .env   # вписать BOT_TOKEN и WEB_APP_URL

# 3. Применить миграции БД
bun run db:migrate

# 4. Запустить
bun run dev            # watch-режим
# или
bun run start          # обычный запуск
```

## Команды

| Команда | Описание |
|---|---|
| `/start` | Приветствие, регистрация и кнопка входа в мини-приложение |
| `/bpm` | Инструмент: определить BPM и тональность трека |
| `/help` | Список доступных команд |

### 🎵 BPM & Key

Отправьте боту аудио (голосовое, трек или файл документом) — он определит:

- ⏱ **темп** в BPM (±2, с октавной нормализацией в диапазон 70–180)
- 🎹 **тональность** и её номер в **Camelot-нотации** (например `A minor → 8A`)
- 📊 **уверенность** определения ключа (0–100%)

Поддерживаемые форматы: `mp3`, `wav`, `ogg/opus`, `m4a`, `aac`, `flac`, `webm` —
декодирование чистое, на WASM, без ffmpeg.

Как это работает:

1. Файл скачивается через Bot API и декодируется в моно-PCM
2. **BPM** — огибающая энергии (onset envelope) + автокорреляция с подбором октавы
3. **Ключ** — хромаграмма через FFT → корреляция с профилями Крумхансла–Шмуклера

## Структура проекта

```
src/
├── index.ts          # точка входа, long polling
├── bot.ts            # создание бота и роутинг команд
├── config.ts         # конфигурация окружения (Zod)
├── constants.ts      # общие константы (метки кнопок и т.п.)
├── types.ts          # общий контекст и утилиты
├── handlers/         # обработчики команд
├── keyboards/        # клавиатуры
├── services/         # бизнес-логика
│   ├── analyze.ts    # детект BPM и тональности
│   ├── audio.ts      # декодирование аудио (WASM, без ffmpeg)
│   └── telegramFiles.ts
├── utils/fft.ts      # radix-2 FFT
└── db/
    ├── schema.ts     # схема таблиц (Drizzle)
    ├── index.ts      # подключение к SQLite
    ├── users.ts      # запросы к таблице users
    ├── migrate.ts    # ручной раннер миграций
    └── migrations/   # SQL-миграции (*.sql)

tests/
├── helpers.ts        # синтез тестового сигнала + WAV/MP3-энкодеры
└── analyze.test.ts   # проверка BPM/Key на заведомо известных сигналах
```

## Тесты

```bash
bun test          # синтезирует сигналы с известным BPM/ключом и проверяет анализатор
```

## Окружение (.env)

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | Токен бота от [@BotFather](https://t.me/BotFather) |
| `WEB_APP_URL` | HTTPS-адрес мини-приложения (кнопка «Открыть BeatLab») |
| `BOT_USERNAME` | Юзернейм бота без `@` (необязательно) |
| `DB_PATH` | Путь к файлу SQLite (по умолчанию `./beatlab.db`) |

## Миграции

SQL-файлы кладутся в `src/db/migrations/` с порядковым номером:

```
0001_init.sql
0002_samples.sql
```

Применить: `bun run db:migrate`.
